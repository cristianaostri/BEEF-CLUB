# Beef Club - Boutique de Carnes

> **Beef Club** es un sitio web responsivo diseñado para una boutique de carnes premium y club de membresía de asados de alta gama. El proyecto presenta una interfaz elegante con una estética oscura y acentos sofisticados.

## ✨ Características del Sitio

- **Diseño Flexbox:** Distribución moderna y flexible que evita desbordamientos estructurales.
- **Navegación Interna:** Enlaces fluidos mediante IDs (`#inicio`, `#talleres`, `#espacio`, `#contacto`).
- **Sección de Catálogo:** Presentación en tarjetas (*cards*) para destacar los cortes premium (Bife de Chorizo, Vacío, Tomahawk y Entraña).
- **Proceso de Suscripción:** Explicación paso a paso de la membresía con una lista ordenada estilizada.

## 🛠️ Tecnologías Utilizadas

- **HTML5:** Estructuración y marcado del contenido.
